# Графика и звук

Визуальный ориентир — Earn to Die: вид сбоку, выцветшая краска, ржавый металл, тяжёлые рамки и закатные пейзажи. Растровая графика создана для проекта с генеративными инструментами по этим референсам и сохранена в WebP; колёса и кузова используют прозрачность.

## Ассеты

Все игровые изображения находятся в `apps/web/public/art`.

| Файлы | Назначение |
| --- | --- |
| `garage.webp` | Фон мастерской |
| `landscape.webp`, `industrial-landscape.webp`, `pass-landscape.webp` | Фоны маршрутов |
| `suv-body.webp`, `truck-body-front-opening.webp`, `r8-body.webp` | Кузова машин без колёс |
| `wheel-0.webp` — `wheel-5.webp` | Уровни колёс |
| `parts.webp` | Атлас иконок улучшений |
| `zombie-profile.webp` | Шесть частей зомби для ходьбы и ragdoll |
| `crate.webp`, `barrel.webp` | Препятствия |
| `plow.webp`, `r8-plow.webp` | Ковши КамАЗа и Audi |
| `asphalt-ground.webp`, `rock-ground.webp` | Покрытия промышленной и горной трасс |
| `evacuation.webp`, `ending-barrier-*.webp` | Финальная сцена |
| `grime.svg` | Текстура панелей интерфейса |

## Геометрия и отрисовка

Габариты кузова, оси, подкрылки и положение ковша задаются в `packages/shared/src/configs/vehicles`. Одни и те же данные используются в гараже и заезде. Размер рисунка сам по себе не меняет физику машины.

Перед показом гаража изображения загружаются и декодируются в `apps/web/src/artwork`. При переключении этапов старый гараж остаётся на экране до готовности нового кузова и колёс.

Тема грунта задаётся этапом, её оформление — в `apps/web/src/configs/terrain.ts`. Текстуры участков дороги создаются и освобождаются по мере движения камеры. Сцепление с поверхностью определяется общими настройками трассы.

Неинтерактивные фоны и подложки занимают всё окно. Положение кнопок и размер машины определяются основной раскладкой интерфейса.

## Звук и лицензии

Игровые записи находятся в `apps/web/public/audio`, назначения — в `apps/web/src/configs/audio.ts`, миксы сцен — в `configs/scenes`.

Источники звуков, авторы и условия использования сохранены в [audio/CREDITS.txt](../apps/web/public/audio/CREDITS.txt). Шрифт Russo One поставляется с [лицензией SIL OFL](../apps/web/public/fonts/OFL.txt).
