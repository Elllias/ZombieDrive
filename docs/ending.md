# Финал: «Сигнал принят»

Предпросмотр: https://178-154-250-113.sslip.io/?scene=ending

Локально: http://localhost:5173/?scene=ending. Нажать «Смотреть финал».
Предпросмотр не создаёт гостя, не начинает заезд и не обращается к API прогресса.
«В игру» убирает параметр `scene` и открывает обычное приложение.

В игре ролик появляется после подтверждённого сервером финиша последнего этапа.
Открытого доступа к Audi недостаточно: нужен финиш с сохранённым результатом.
После ролика доступны обычные итоги заезда; начисление награды не меняется.

## Сценарий

| Время | Сцена |
| --- | --- |
| 0–4,2 с | Audi подъезжает к эвакуационному пункту на рассвете. |
| 4,2–7,2 с | «Пост эвакуации, приём. Я прошёл перевал.» |
| 7,2–9,2 с | «Вижу тебя. Открываю ворота. Проезжай!» Шлагбаум открывается. |
| 9,2–13,3 с | Машина проезжает за ворота. «За воротами безопасно.» |
| 13,3–16 с | Шлагбаум закрывается. «Три дороги позади.» |
| После 16 с | «ТЫ ВЫБРАЛСЯ», музыка меню, выход и повторный просмотр. |

Есть пропуск, звук, остановка при сворачивании и возобновление по кнопке.
При уменьшенной анимации автомобиль неподвижен, сюжет передают подписи.
Звук двигателя, ветер и рация используют существующие игровые записи.
Автомобиль и колёса отрисованы отдельными слоями из игровых ассетов.

Сценарий и длительность: `apps/web/src/configs/scenes/ending.ts`.
Движение: `endingMotion.ts`; звук: `EndingAudio.ts`; оформление: `ui/ending*.css`.
Общий таймер интро и финала: `ui/cutscene/useCutscenePlayback.ts`.
